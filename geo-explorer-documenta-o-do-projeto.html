📖 O que é o Geo-Explorer

O Geo-Explorer transforma o aprendizado em tecnologia em uma aventura épica. Cada trilha é uma jornada temática — com módulos progressivos, missões especiais, badges e recompensas — tornando o caminho até a maestria técnica motivador e imersivo.

A plataforma foi criada como um desafio prático de desenvolvimento assistido por IA, usando o IBM Bob como parceiro em todas as etapas: ideação, criação de dados, definição dos slash commands, escrita dos testes e automação.

Três comandos principais movem a plataforma, todos operando dentro do IBM Bob:

ComandoDescrição
/trilha <tecnologia>Exibe o plano completo de exploração de uma trilha
/desafio <tecnologia> <nivel>Gera uma missão de código temática e narrativa
/certificado <nome> <tecnologia>Emite um certificado épico de explorador

⚙️ Como executar o projeto

Pré-requisitos

  • IBM Bob instalado e configurado
  • Python 3.10+ (apenas para rodar os testes)
  • Nenhuma dependência externa — usa somente a biblioteca padrão do Python

Instalação

1. Crie seu repositório no GitHub

  1. Acesse github.com e faça login na sua conta
  2. Clique em "New" (botão verde) ou acesse github.com/new
  3. Preencha os campos:
    • Repository name: geo-explorer
    • Description: Plataforma fictícia de exploração — IBM Bob
    • Marque Public
    • Não marque "Add a README file" (já temos um)
  4. Clique em "Create repository"
  5. Copie a URL — será algo como https://github.com/seu-usuario/geo-explorer.git

2. Clone e aponte para o seu repositório

# Clone o repositório original
git clone https://github.com/vinicioscaires/geo-explorer.git
cd geo-explorer

# Troque o remote para apontar para o SEU repositório
git remote set-url origin https://github.com/SEU-USUARIO/geo-explorer.git

# Suba o projeto para o seu GitHub
git push --set-upstream origin master
💡 Substitua SEU-USUARIO pelo seu nome de usuário do GitHub.

🧭 Como usar os comandos

Os comandos são slash commands do IBM Bob. Abra o IBM Bob no workspace do projeto e digite no chat.

/trilha <tecnologia>

Exibe o plano completo: módulos temáticos, missões especiais, badges, habilidades e recompensa final. Busca case-insensitive, aceita nome parcial.

/trilha Python
/trilha TypeScript
/trilha "Cloud Computing"
/desafio <tecnologia> <nivel>

Gera uma missão narrativa com tipo, tempo, dificuldade em estrelas, XP, entrada/saída, pistas e casos de teste.

/desafio Python Iniciante
/desafio JavaScript Intermediário
/desafio DevOps Avançado
NívelDificuldadeXP
Iniciante⭐☆☆☆☆300–500 XP
Intermediário⭐⭐⭐☆☆600–900 XP
Avançado⭐⭐⭐⭐⭐1.000–1.500 XP
/certificado <nome> <tecnologia>

Emite certificado épico com ID único GEO-XXXXXXXXXX, dados reais da trilha e URL de verificação.

/certificado "Ada Lovelace" Python
/certificado "Alan Turing" Java

🧪 Como executar os testes

Rodar todos os testes

python testes/executar_testes.py

Rodar um arquivo específico

# /trilha
python -m unittest testes/unitarios/test_trilha.py -v

# /desafio
python -m unittest testes/unitarios/test_desafio.py -v

# /certificado
python -m unittest testes/unitarios/test_certificado.py -v

# Jornada completa (fluxo)
python -m unittest testes/fluxo/test_jornada_explorador.py -v

🔧 Melhorias realizadas

1

Arquitetura orientada a dados

geo_trilhas.json centraliza todas as informações. Os três comandos leem do mesmo arquivo, garantindo consistência total — XP, badges e recompensa nunca divergem.

2

Busca tolerante a variações

A função buscar_trilha é case-insensitive e busca por tecnologia e nome. /trilha java e /trilha Galáxia Java retornam o mesmo resultado.

3

Validação de entradas inválidas

Nulo, vazio ou inexistente retorna None — nunca lança exceção. Validado por TestEntradasInvalidas.

4

Testes de fluxo end-to-end

A jornada completa /trilha → /desafio → /certificado é validada em 4 etapas, garantindo que tecnologia, nível, XP e badges sejam coerentes entre os três comandos.

5

Runner com relatório persistido

Descoberta automática de testes, exibição formatada no terminal e relatório salvo em testes/resultados.txt.

6

IDs únicos e verificáveis no certificado

Formato GEO-XXXXXXXXXX com URL de verificação associada. Testes validam formato, tamanho e unicidade.

7

Servidor MCP expondo 3 ferramentas

mcp/server.py expõe geo_trilha, geo_desafio e geo_certificado para que outros clientes MCP acessem os recursos da plataforma.
